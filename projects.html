🔐 Interactive Research Software

FracSync Lab — Fractional-Order Network Synchronization Bench

A single-file browser laboratory for drive–response synchronization of Caputo fractional-order dynamical systems discretized via the Adams–Bashforth–Moulton predictor–corrector scheme (Diethelm, Ford, Freed). Features 18 dynamical systems across three families (3D/4D chaotic attractors, multi-neuron real neural networks, and 8D quaternion-valued neural networks in ℙ), 5 feedback controllers (Linear, Fixed-time, Sliding mode, Adaptive gain, Impulsive), an inline non-blocking Web Worker engine with progress reporting, customizable time span T and step h, real-time phase portraits, and reproducible Python code generation.

📐 Open Educational Platform

Maths for All — Open Educational Mathematics Platform

A free, open-access educational initiative offering intuitive, visualization-rich courses across undergraduate and graduate mathematics, including Linear Algebra, Multivariable Calculus, Real Analysis, and Differential Equations. Focuses on bridging theoretical rigor with computational intuition and real-world scientific applications.
