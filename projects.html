🔐 Interactive Research Software

FracSync Lab — Fractional-Order Network Synchronization Bench

A single-file browser laboratory for drive–response synchronization of Caputo fractional-order dynamical systems discretized via the Adams–Bashforth–Moulton predictor–corrector scheme (Diethelm, Ford, Freed). Features 18 dynamical systems across three families (3D/4D chaotic attractors, multi-neuron real neural networks, and 8D quaternion-valued neural networks in ℙ), 5 feedback controllers (Linear, Fixed-time, Sliding mode, Adaptive gain, Impulsive), an inline non-blocking Web Worker engine with progress reporting, customizable time span T and step h, real-time phase portraits, and reproducible Python code generation.

🌀 Mathematical Art & Scientific Visualization

Phase Space Prints — Differential Equations to Fine Art Prints

A single-file browser application that renders dynamical systems—strange attractors, fractional-order systems (Grünwald–Letnikov with $L=1000$ history), iterated maps, forced oscillators (Poincaré sections), and custom user-defined differential equations—into high-resolution canvas prints, posters, and wallpapers. Features a CPU density buffer with sub-pixel bilinear splatting, 99.5th percentile logarithmic tone mapping, 8 curated palettes, interactive 3D rotation, gallery-grade typography captions, and a hand-written recursive-descent math expression compiler with strictly zero eval.

📚 Private Offline AI Research Assistant

ScholarLocal — 100% Offline Research Assistant for Mathematics & Control Theory

A private, local research-paper agent running on Ollama over personal mathematics libraries (fractional calculus, neural network synchronization, and control theory). Features section-aware chunking preserving theorem and equation blocks via PyMuPDF, hybrid retrieval combining dense vector search (ChromaDB) with math-aware BM25 and Reciprocal Rank Fusion (RRF), exact paper + page citations ([AuthorYear, p. X]), structured theorem/assumption extraction, and an interactive Streamlit UI with PDF page viewer. Zero document content ever leaves the user's computer.

🕹️ Arcade Browser Game & PWA

Neon Air Hockey — WebRTC Peer-to-Peer Arcade Game & PWA

A fast-paced neon arcade air hockey game built with vanilla HTML5 canvas, real-time 2D physics with continuous sub-stepped collision resolution, and synthesized Web Audio sound effects. Features 3 distinct game modes: Vs Computer (Easy, Medium, Hard AI with predictive defensive alignment and attack angles), Two Players, One Screen (touch-split screen or keyboard WASD + mouse), and Online Multiplayer using peer-to-peer WebRTC via PeerJS with 4-character invite codes and direct browser-to-browser state streaming. Includes 3 dynamic center-zone power-ups (Freeze, Multi-puck, and Goal Shield) and full Progressive Web App (PWA) offline installation.
