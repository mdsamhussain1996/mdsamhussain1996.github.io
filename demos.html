Governing Equations

The drive system is a Lorenz-type chaotic oscillator:

$$\dot{x}_1 = \sigma(x_2 - x_1), \quad \dot{x}_2 = x_1(\rho - x_3) - x_2, \quad \dot{x}_3 = x_1 x_2 - \beta x_3$$

with classical parameters \(\sigma = 10,\; \rho = 28,\; \beta = 8/3\). The response system has the same structure but receives a coupling signal proportional to the synchronization error:

$$\dot{y}_1 = \sigma(y_2 - y_1) - k(y_1 - x_1)$$ $$\dot{y}_2 = y_1(\rho - y_3) - y_2 - k(y_2 - x_2)$$ $$\dot{y}_3 = y_1 y_2 - \beta y_3 - k(y_3 - x_3)$$

The synchronization error is \(e(t) = y(t) - x(t)\). When \(k\) is large enough, \(\|e(t)\| \to 0\) as \(t \to \infty\), meaning the response system asymptotically synchronizes with the drive. This is exactly the phenomenom studied in my fractional-order quaternion-valued neural network synchronization research — here shown in the simpler integer-order Lorenz setting for clarity.

In my published work, the fractional derivative \({}^C\!D^\alpha\) (Caputo sense, \(0 < \alpha < 1\)) replaces \(d/dt\), encoding memory effects. The coupling controller \(u(t) = -k\,e(t)\) is designed via Lyapunov's direct method using the fractional Razumikhin theorem.
